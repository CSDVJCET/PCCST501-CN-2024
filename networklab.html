Experiment 01 Linux Networking

Linux Network Administration Commands & Interface Configuration

Practice essential Linux CLI tools: ip addr, ip route, ss, netstat, ping, traceroute, and tcpdump.

Terminal Commands 
# Inspect IP and MAC addresses on all interfaces
ip addr show

# View active TCP/UDP listening ports and processes
ss -tulnp

# Trace routing hops to destination
traceroute -n 8.8.8.8
