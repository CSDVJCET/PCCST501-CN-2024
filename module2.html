1. Transport Layer Protocols: UDP vs. TCP

Feature UDP (User Datagram Protocol) TCP (Transmission Control Protocol)
Connection State Connectionless (No Handshake) Connection-Oriented (3-Way Handshake)
Header Size Fixed 8 Bytes 20 to 60 Bytes (with options)
Reliability Unreliable (No ACKs or Retransmission) 100% Reliable (ACKs, Checksum, Retransmission)
Flow & Congestion None Sliding Window Flow Control + AIMD Congestion Control
Use Cases DNS, VoIP, Live Video Streaming (RTP) HTTP/HTTPS, SSH, FTP, SMTP

2. Berkeley Sockets API & I/O Multiplexing

Socket system calls in POSIX C (from Stevens UNP Vol 1):

  1. int socket(int domain, int type, int protocol); → Creates communication endpoint.
  2. int bind(int sockfd, const struct sockaddr *addr, socklen_t addrlen); → Assigns local IP/Port.
  3. int listen(int sockfd, int backlog); → Puts socket in passive listening state.
  4. int accept(int sockfd, struct sockaddr *addr, socklen_t *addrlen); → Accepts incoming TCP connection.
  5. int select(int nfds, fd_set *readfds, fd_set *writefds, fd_set *exceptfds, struct timeval *timeout); → Synchronous I/O multiplexing.
Hands-On Code: Concurrent TCP Server with select()

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <sys/select.h>

#define PORT 9000
#define MAX_CLIENTS 30

int main() {
    int master_socket, client_socket[MAX_CLIENTS], max_clients = MAX_CLIENTS, activity, i, valread, sd;
    int max_sd, new_socket;
    struct sockaddr_in address;
    char buffer[1025];
    fd_set readfds;

    for (i = 0; i < max_clients; i++) client_socket[i] = 0;
    master_socket = socket(AF_INET, SOCK_STREAM, 0);

    address.sin_family = AF_INET;
    address.sin_addr.s_addr = INADDR_ANY;
    address.sin_port = htons(PORT);

    bind(master_socket, (struct sockaddr *)&address, sizeof(address));
    listen(master_socket, 5);
    printf("TCP Select Server listening on port %d...\n", PORT);
    return 0;
}

3. Network Layer, IPv4 Subnetting & Routing Algorithms

The Network Layer provides host-to-host logical routing across diverse networks.

Routing Algorithm Comparison: Link-State vs. Distance-Vector
Metric Link-State (OSPF) Distance-Vector (RIP)
Algorithm Dijkstra's Shortest Path First (SPF) Bellman-Ford Distributed Equation
Knowledge Scope Global topology database (LSA flooding) Local knowledge (Distance vectors to immediate neighbors)
Convergence Fast, loop-free via hierarchy (Areas) Slow, vulnerable to Count-to-Infinity
