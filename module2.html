Transport Layer, UNIX Sockets & Network Layer

Prescribed References: Forouzan (Ch 3, 4, 8), Stevens UNP Vol 1 (Ch 3-6, 8, 14), Seth & Venkatesulu (Ch 14) • 18 Contact Hours

1. Transport Layer Protocols: TCP vs. UDP

The transport layer provides logical, process-to-process communication between application processes running on different hosts using 16-bit Port Numbers.

UDP (User Datagram Protocol)
  • Connectionless, minimal 8-byte header overhead.
  • No handshake, no congestion/flow control, preserves message boundaries.
  • Used in DNS, DHCP, VoIP, streaming video.
TCP (Transmission Control Protocol)
  • Connection-oriented, reliable byte-stream delivery.
  • 3-Way Handshake, Flow Control (Receive Window rwnd), and Congestion Control (cwnd).
  • Used in HTTP/HTTPS, SSH, SMTP, FTP.
TCP Congestion Control Algorithms (AIMD & Reno)
  • Slow Start: cwnd starts at 1 MSS and doubles every RTT (exponential growth) until reaching ssthresh.
  • Congestion Avoidance: Linear increase (Additive Increase: $+1\text{ MSS}$ per RTT).
  • Fast Retransmit & Recovery: Upon receiving 3 duplicate ACKs, TCP immediately retransmits the missing segment, sets $\text{ssthresh} = \text{cwnd} / 2$, and enters Fast Recovery without resetting to 1 MSS.

2. UNIX Sockets API & I/O Multiplexing (Stevens UNP)

Berkeley Sockets API provides the standard interface between user-space network applications and the operating system kernel's TCP/IP stack.

I/O Multiplexing: `select()` vs. `poll()`

Allows a single process thread to monitor multiple file descriptors (listening sockets, connected client sockets, stdin) simultaneously and block until any descriptor becomes ready for reading/writing.

#include <sys/socket.h>

fd_set readfds;
FD_ZERO(&readfds);
FD_SET(server_fd, &readfds);

3. Network Layer: Addressing, Subnetting & Routing

IPv4 Addressing & CIDR (RFC 4632)

Subnetting divides a large network into smaller sub-networks using prefix length notation (`/n`). Total usable hosts = $2^{32 - n} - 2$.

Unicast Routing Protocols
  • Distance Vector (Bellman-Ford / RIP): Exchanges routing tables with direct neighbors every 30s. Metric: Hop count (Max 15 hops).
  • Link-State (Dijkstra SPF / OSPF): Floods LSAs to entire Autonomous System. Every router builds a complete topology tree. Fast convergence.
  • Path Vector (BGP-4): Inter-domain routing protocol carrying AS-PATH attributes to eliminate loops and enforce policy routing.

4. Linux Kernel Routing Architecture (Seth & Venkatesulu)

The Linux network subsystem utilizes the Forwarding Information Base (FIB - `fib_table`) organized as a radix trie for longest-prefix matching, complemented by the Routing Cache (`rtable`) for rapid route lookups.

Linux Route Configuration CLI
# Inspect kernel routing table
ip route show

# Add static route to subnet 10.10.0.0/16 via gateway 192.168.1.1
sudo ip route add 10.10.0.0/16 via 192.168.1.1 dev eth0
