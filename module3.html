Data Link Layer, Ethernet & Wireless LANs

Prescribed References: Forouzan (Ch 5 & 6), Stevens UNP Vol 1 (Ch 29) • 11 Contact Hours

1. Data Link Control (DLC) & Error Control

The Data Link Layer is responsible for node-to-node frame transfer across a single physical link.

Framing Techniques
  • Character-Oriented (Byte Stuffing): Inserts ESC before data bytes matching FLAG or ESC.
  • Bit-Oriented (Bit Stuffing): Flags are 01111110. Sender inserts a 0 after any sequence of 5 consecutive 1s in payload.
Cyclic Redundancy Check (CRC)

Given Data $D$ and Generator Polynomial $G$ of degree $r$: Appends $r$ zeros to $D$, performs binary modulo-2 division (XOR) by $G$. The resulting remainder $R$ is appended as the FCS checksum.

2. Multiple Access Protocols (MAC) & CSMA/CD

CSMA/CD (Carrier Sense Multiple Access with Collision Detection)

"Listen while talk". If collision is detected during frame transmission, node aborts, sends 32-bit Jamming signal, and executes Binary Exponential Backoff (waiting $R \times 512$ bit times, $R \in [0, 2^k - 1]$).

Standard Ethernet Minimum Frame Size Condition:

$T_{trans} \ge 2 \times T_{prop} \implies \frac{L_{min}}{\text{Bandwidth}} \ge 2 \times \frac{\text{Distance}}{v} \implies L_{min} = 64 \text{ Bytes (512 bits)}$

Layer-2 Switches: Maintain CAM (Content Addressable Memory) MAC address table to forward frames selectively to destination ports, eliminating collisions. Uses Spanning Tree Protocol (IEEE 802.1D) to avoid bridging loops.

4. Wireless LANs (802.11), Mobile IP & Raw Sockets

CSMA/CA & Hidden Station Problem: In wireless networks, physical collision detection is impossible due to signal fading. IEEE 802.11 uses RTS/CTS (Request to Send / Clear to Send) virtual carrier sensing with NAV (Network Allocation Vector).

Mobile IP: Uses Home Agent (HA), Foreign Agent (FA), and Care-of Address (CoA) with IP-in-IP encapsulation to route packets to roaming mobile hosts.
