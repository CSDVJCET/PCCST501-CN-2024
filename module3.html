1. Framing, Flow Control & Error Control

The Data Link Layer transforms physical raw bit streams into discrete Frames and handles node-to-node hop reliability.

Framing Techniques
  • Character / Byte Stuffing: DLE (Data Link Escape) bytes inserted before escape sequences in character-oriented protocols.
  • Bit Stuffing: A 0-bit is automatically stuffed after five consecutive 1s (11111 → 111110) to avoid premature flag delimiter matches (01111110).

2. Error Detection & Correction (CRC & Hamming Code)

Cyclic Redundancy Check (CRC)

Uses binary Modulo-2 polynomial XOR division. Append $n$ zero bits to $k$-bit data word, divide by $(n+1)$-bit generator polynomial $G(x)$. The $n$-bit remainder is the Frame Check Sequence (FCS).

Hamming (7,4) Code

Encodes 4 data bits $(d_3, d_2, d_1, d_0)$ with 3 parity bits $(p_1, p_2, p_3)$ into a 7-bit codeword. Single-bit errors generate non-zero syndrome $(s_2 s_1 s_0)$ that pinpoints the exact corrupted bit for auto-correction!

Hands-On Code: Linux PF_PACKET Raw Socket Sniffer
assets/handson_code/module3/raw_socket_packet_sniffer.c 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/socket.h>
#include <netinet/ip.h>
#include <netinet/if_ether.h>
#include <arpa/inet.h>

int main() {
    int sock_raw = socket(AF_PACKET, SOCK_RAW, htons(ETH_P_ALL));
    if (sock_raw < 0) {
        perror("Raw Socket Error (Run with sudo)");
        return 1;
    }
    unsigned char buffer[65536];
    printf("[*] Listening for raw Ethernet frames...\n");
    while (1) {
        int data_size = recvfrom(sock_raw, buffer, 65536, 0, NULL, NULL);
        struct ethhdr *eth = (struct ethhdr *)buffer;
        printf("Ethernet: Dest MAC %.2X:%.2X:%.2X:%.2X:%.2X:%.2X | Protocol: 0x%.4X | Bytes: %d\n",
            eth->h_dest[0], eth->h_dest[1], eth->h_dest[2], eth->h_dest[3], eth->h_dest[4], eth->h_dest[5],
            ntohs(eth->h_proto), data_size);
    }
    return 0;
}
