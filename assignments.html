Continuous Internal Evaluation (CIE)

Course Assignments & Mini Project Ideas

Coursework briefs, rubrics, and project topics covering 15 marks of Continuous Internal Evaluation.

Assignment 01 Max Marks: 10

Application & Transport Layer Protocol Analysis

Perform Wireshark packet capture on standard HTTP and HTTPS requests. Compare DNS recursive vs iterative query flows, and explain the TCP 3-Way Handshake with window scale options.

Assignment 02 Max Marks: 10

VLSM Subnet Design & Link State Routing Trace

Design a Variable Length Subnet Masking (VLSM) topology for an enterprise network with 5 departments. Trace Dijkstra's algorithm step-by-step for a 7-node network graph.

Recommended Mini Project Topics

1. Multi-Client Encrypted Chat Server

Built in Python/C with I/O multiplexing (`select()`) and TLS socket encryption.

2. Network Packet Sniffer & IDS

Using Linux `PF_PACKET` raw sockets to detect port scans and ARP poisoning attacks.

3. Web-based Routing Simulator

Interactive visualizer for Bellman-Ford Count-to-Infinity and OSPF convergence.
