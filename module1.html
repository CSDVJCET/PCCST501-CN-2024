1. Overview of the Internet & Protocol Layering

The Internet architecture is fundamentally partitioned into the Network Edge (end-systems, hosts, servers) and the Network Core (interconnected routers, switches, and packet switches).

TCP/IP 5-Layer Protocol Stack vs. OSI 7-Layer Model
Layer PDU Core Responsibility Standard Protocols
5. Application Message User interaction & high-level network application services HTTP, HTTPS, DNS, SMTP, FTP, BitTorrent
4. Transport Segment / Datagram Process-to-process delivery, port multiplexing, reliability TCP (RFC 793), UDP (RFC 768)
3. Network Datagram / Packet Host-to-host logical addressing & unicast/multicast routing IPv4, IPv6, ICMP, OSPF, RIP, BGP
2. Data Link Frame Node-to-node hop delivery, MAC addressing, framing & error control IEEE 802.3 Ethernet, IEEE 802.11 Wi-Fi, PPP
1. Physical Bits Physical transmission of raw bits over guided/unguided media UTP Cat 6, Optical Fiber, Radio Waves

2. Client-Server Architecture & Application Layer Services

Network applications are structured under two dominant paradigms:

Client-Server Paradigm
  • Always-on, dedicated server with static IP address.
  • Clients communicate solely via central server (not directly).
  • Examples: Web (HTTP), Email (SMTP/IMAP), File Transfer (FTP).
Peer-to-Peer (P2P) Paradigm
  • No fixed central server; arbitrary pairs of hosts (peers) communicate.
  • Highly scalable (Self-scalability: new peers bring service capacity).
  • Example: BitTorrent file swarming.

3. Standard Application Layer Protocols (HTTP, FTP, SMTP, DNS)

Protocol Port / Transport Key Features & Architecture
HTTP/1.1 & HTTP/2 TCP 80 / 443 Stateless request-response. HTTP/1.1 persistent connections vs HTTP/2 binary framing multiplexing.
FTP (RFC 959) TCP 21 (Control) & TCP 20 (Data) Out-of-band control signaling; stateful server maintains current working directory.
SMTP / MIME TCP 25 Push protocol for mail relay; MIME encodes binary multimedia into 7-bit ASCII.
DNS (RFC 1035) UDP 53 (TCP 53 for zone transfer) Hierarchical distributed database resolving hostnames to IP addresses. Supports recursive & iterative queries.

import socket, threading

def handle_client(client_sock):
    request = client_sock.recv(1024).decode('utf-8')
    response_body = "<html><body><h1>VJCET PCCST501 HTTP Server</h1><p>Faculty: Prof. Anju Markose</p></body></html>"
    response = f"HTTP/1.1 200 OK\r\nContent-Type: text/html\r\nContent-Length: {len(response_body)}\r\n\r\n{response_body}"
    client_sock.sendall(response.encode('utf-8'))
    client_sock.close()

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.bind(('127.0.0.1', 8080))
server.listen(5)
print("[*] HTTP Server running on http://127.0.0.1:8080")
