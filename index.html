Syllabus Breakdown

Course Modules Overview

Detailed curriculum topics aligned with prescribed Forouzan & Stevens textbooks

Module 1 6 Hours

Application Layer & P2P

Internet architecture, protocol layering, HTTP/1.1 & HTTP/2, FTP dual-channel, SMTP/MIME, DNS hierarchy, and BitTorrent P2P swarming.

Study Module 1 Notes
Exam Notes
Module 2 18 Hours

Transport & Network Layer

TCP/UDP, Sockets API (Stevens UNP), `select()`/`poll()`, IPv4/IPv6, CIDR Subnetting, Routing: OSPF & RIP, QoS, Linux Kernel routing table.

Study Module 2 Notes
Exam Notes
Module 3 11 Hours

Data Link Layer & WLAN

Framing, CRC & Hamming codes, MAC protocols, CSMA/CD, IEEE 802.3 Ethernet, IEEE 802.11 Wi-Fi, Mobile IP, and Linux `PF_PACKET` raw sockets.

Study Module 3 Notes
Exam Notes
Module 4 9 Hours

Network Mgmt & Physical Layer

SNMP, ASN.1/BER, MIB-II, Signals, Nyquist & Shannon capacity limits, Line Coding (Manchester/AMI), FDM/TDM, and Transmission Media.

Study Module 4 Notes
Exam Notes
Interactive Protocol Workbench

Live Network Simulator Suite & Video Labs

Simulate protocol operations directly in your browser without complex software setup. Test HTTP/2, trace DNS query trees, step through TCP 3-way handshakes, simulate Sliding Window ARQ, calculate CRC remainders, and render digital line coding waveforms!

Module 1: HTTP Inspector & DNS Query Resolver

Trace recursive vs iterative DNS queries and inspect live HTTP headers.

Module 2: TCP Handshake & Dijkstra Routing

Step-by-step state machine transition and OSPF shortest path tree generation.

Module 3: Sliding Window ARQ & Hamming (7,4) Corrector

Simulate packet drops, timeouts, and single-bit error auto-correction.
