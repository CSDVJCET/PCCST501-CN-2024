Syllabus Breakdown

Course Modules Overview

Detailed curriculum topics aligned with prescribed Forouzan & Stevens textbooks

Module 1 6 Hours

Application Layer & P2P

Internet architecture, protocol layering, HTTP/1.1 & HTTP/2, FTP dual-channel, SMTP/MIME, DNS hierarchy, and BitTorrent P2P swarming.

Study Module 1
Module 2 18 Hours

Transport & Network Layer

TCP/UDP, Sockets API (Stevens UNP), `select()`/`poll()`, IPv4/IPv6, CIDR Subnetting, Routing: OSPF & RIP, QoS, Linux Kernel routing table.

Study Module 2
Module 3 11 Hours

Data Link Layer & WLAN

Framing, CRC & Hamming codes, MAC protocols, CSMA/CD, IEEE 802.3 Ethernet, IEEE 802.11 Wi-Fi, Mobile IP, and Linux `PF_PACKET` raw sockets.

Study Module 3
Module 4 9 Hours

Network Mgmt & Physical Layer

SNMP, ASN.1/BER, MIB-II, Signals, Nyquist & Shannon capacity limits, Line Coding (Manchester/AMI), FDM/TDM, and Transmission Media.

Study Module 4
