🎯 Aim

Implement RIPv2 routing for the network shown in Figure 1. Once the routes are set up, display the routing table and verify the connectivity using ping.

📚 What is RIPv2?

RIPv2 is the routing protocol used in this experiment to allow routers to exchange routing information for the networks connected to them. Instead of manually entering every remote route, the routers advertise their participating networks using RIP.

Enable RIPv2 on participating routers.

Step 5 – Display routing table

Step 6 – Verify connectivity
