📖 Experiment Overview

The experiment uses an IPv6 network containing five /64 subnets. Routers R1, R2 and R3 are configured with IPv6 addresses on their participating interfaces. RIPng is enabled on those interfaces so that IPv6 routing information can be exchanged dynamically. The source manual identifies the five subnets and the router/host addressing used below. fileciteturn37file0

🧠 What is RIPng?

RIPng is the IPv6 version of the Routing Information Protocol used for dynamic exchange of routing information between IPv6 routers.

R
Router learns remote IPv6 networks.
I
Routing information is exchanged dynamically.
P
Routes become available in the IPv6 routing table.

In this experiment, RIPng is enabled directly on the participating IPv6 interfaces using ipv6 rip RIPNG enable. fileciteturn37file7

🧭 How the Routing Works

PC-A → R1 → RIPng → R2 / R3 → Remote IPv6 subnet

1. Connected networks
Routers know their directly connected /64 networks.
2. RIPng exchange
Routers exchange IPv6 routing information.
3. Routing table
Remote routes become available.

📝 Procedure

Step 1

Create the IPv6 topology in Cisco Packet Tracer according to Figure 3.

Step 2

Configure the IPv6 addresses on R1, R2 and R3 interfaces.

Step 3

Enable IPv6 unicast routing on each participating router.

Step 4

Enable RIPng using ipv6 rip RIPNG enable on the required interfaces.

Step 5

Bring the configured interfaces up using no shutdown.

Step 6

Configure PC-A, PC-B and PC-C with their IPv6 addresses and default gateways.

Step 7

Use show ipv6 protocols to verify RIPng.

Step 8

Use show ipv6 route to verify learned IPv6 routes.

Step 9

Ping PC-B and PC-C from PC-A and verify connectivity.

🐞 Troubleshooting

ProblemWhat to check
Interface is downCheck the IPv6 address and use no shutdown.
No RIPng routesCheck ipv6 unicast-routing and ipv6 rip RIPNG enable.
PC cannot reach gatewayVerify the PC IPv6 address and default gateway.
Remote subnet unreachableUse show ipv6 route and check whether the required RIPng route is present.
Ping fails after configurationCheck interface addressing, link status, RIPng configuration and PC addressing.
