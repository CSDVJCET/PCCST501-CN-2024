After completing this experiment, the student will be able to:

  • Identify User EXEC, Privileged EXEC and configuration modes.
  • Obtain router and interface information.

  • Identify DTE/DCE controller information.

Remember: save the running configuration to preserve it for the next boot.

Replace the interface identifier with the serial interface available on your router.

The output can be used to identify DTE/DCE information.

Important: Configure clock rate on the DCE side of a serial connection.

Serial interface
Router# configure terminal
Router(config)# interface serial 0/0/0
Router(config-if)# ip address 192.168.1.1 255.255.255.252
Router(config-if)# clock rate 64000
Router(config-if)# no shutdown
Ethernet interface

Router(config-if)# ip address 192.168.10.1 255.255.255.0
Router(config-if)# no shutdown

Router# show ip interface brief

🧪 Experiment

Aim

To familiarize students with commonly used Cisco IOS router commands for identifying router modes, obtaining router and interface information, viewing routing information, saving configurations, checking controller details, and configuring serial and Ethernet interfaces.

Requirements

  • Cisco Packet Tracer
  • Router device
  • Console/CLI access
  • Basic IPv4 and subnet-mask knowledge

📝 Procedure

  1. Open Cisco Packet Tracer and place a router in the workspace.
  2. Open the router CLI and observe the initial prompt.
  3. Use enable and identify Privileged EXEC mode.
  4. Use configure terminal to enter Global Configuration mode.
  5. Use the required show commands to inspect router information.
  6. View routing protocols and the routing table.
  7. View command history, clock and hosts.
  8. View detailed and brief interface statistics.
  9. Check the serial controller for DTE/DCE information.
  10. Configure serial and Ethernet interfaces with IP addresses and masks.
  11. Set clock rate on the DCE serial interface where required.
  12. Enable interfaces using no shutdown.
  13. Verify using show ip interface brief.
  14. Save the configuration using copy running-config startup-config.
