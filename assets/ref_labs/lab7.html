💬 What is a Multi-User Chat Server?

A multi-user chat server is a centralized application that allows multiple clients to communicate with each other simultaneously over a network. Each connected client sends messages to the server, and the server distributes those messages to the appropriate clients.

Key Idea

Clients never communicate directly with one another. All communication passes through the TCP server, which manages connections and forwards messages.

🔒 Why TCP for Chat Applications?

Advantages
  • Reliable communication
  • No packet loss
  • Messages arrive in order
  • Error checking
  • Flow control
  • Congestion control
  • Connection-oriented protocol
Why Not UDP?
  • Packets may be lost.
  • Packets may arrive out of order.
  • No delivery guarantee.
  • No acknowledgements.
  • Not suitable for chat applications.

🧵 Why Does a Chat Server Need Threads?

A single-threaded server can communicate with only one client at a time. If multiple clients connect simultaneously, the remaining clients must wait until the current communication finishes.

Solution: Create one thread for every connected client. Each thread independently receives messages from its client while the main server continues accepting new connections.

💻 TCP Multi-User Chat Server (server.c)

This server uses POSIX Threads (pthread) to handle multiple clients simultaneously. Each connected client gets a dedicated thread. When one client sends a message, the server broadcasts it to all the remaining connected clients. 


#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>
#include <pthread.h>

#define PORT 8080
#define MAX_CLIENTS 10
#define BUFFER_SIZE 1024

typedef struct
{
    int socket;
    char name[50];
} Client;

Client clients[MAX_CLIENTS];
int clientCount = 0;

pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;

void broadcast(char message[], int sender)
{
    pthread_mutex_lock(&mutex);

    for(int i=0;i<clientCount;i++)
    {
        if(clients[i].socket != sender)
        {
            send(clients[i].socket,
                 message,
                 strlen(message),
                 0);
        }
    }

    pthread_mutex_unlock(&mutex);
}

void removeClient(int socket)
{
    pthread_mutex_lock(&mutex);

    for(int i=0;i<clientCount;i++)
    {
        if(clients[i].socket == socket)
        {
            for(int j=i;j<clientCount-1;j++)
                clients[j]=clients[j+1];

            clientCount--;
            break;
        }
    }

    pthread_mutex_unlock(&mutex);
}

void *clientHandler(void *arg)
{
    int clientSocket = *(int *)arg;

    char name[50];
    char message[BUFFER_SIZE];
    char finalMessage[BUFFER_SIZE+100];

    recv(clientSocket,name,sizeof(name),0);

    printf("%s joined the chat.\n",name);

    sprintf(finalMessage,"%s joined the chat.",name);
    broadcast(finalMessage,clientSocket);

    while(1)
    {
        int bytes =
        recv(clientSocket,
             message,
             sizeof(message),
             0);

        if(bytes<=0)
            break;

        message[bytes]='\0';

        sprintf(finalMessage,
                "%s : %s",
                name,
                message);

        printf("%s\n",finalMessage);

        broadcast(finalMessage,
                  clientSocket);
    }

    printf("%s disconnected.\n",name);

    sprintf(finalMessage,
            "%s left the chat.",
            name);

    broadcast(finalMessage,
              clientSocket);

    removeClient(clientSocket);

    close(clientSocket);

    pthread_exit(NULL);
}

int main()
{
    int serverSocket;
    int clientSocket;

    struct sockaddr_in serverAddr;
    struct sockaddr_in clientAddr;

    socklen_t addrSize;

    serverSocket = socket(AF_INET,
                          SOCK_STREAM,
                          0);

    serverAddr.sin_family = AF_INET;
    serverAddr.sin_port = htons(PORT);
    serverAddr.sin_addr.s_addr = INADDR_ANY;

    bind(serverSocket,
         (struct sockaddr *)&serverAddr,
         sizeof(serverAddr));

    listen(serverSocket,MAX_CLIENTS);

    printf("\n=================================\n");
    printf(" Multi-User TCP Chat Server\n");
    printf("=================================\n");
    printf("Listening on Port %d...\n\n",PORT);

    while(1)
    {
        addrSize = sizeof(clientAddr);

        clientSocket =
        accept(serverSocket,
               (struct sockaddr *)&clientAddr,
               &addrSize);

        pthread_mutex_lock(&mutex);

        clients[clientCount].socket = clientSocket;

        clientCount++;

        pthread_mutex_unlock(&mutex);

        pthread_t tid;

        pthread_create(&tid,
                       NULL,
                       clientHandler,
                       &clients[clientCount-1].socket);

        pthread_detach(tid);
    }

    close(serverSocket);

    return 0;
}

📝 Server Program Explanation

The server maintains an array of connected clients. Whenever a new client joins, its socket descriptor is stored in this array so that messages can later be broadcast to every connected client.

Whenever a client sends a message, the broadcast() function iterates through every connected client and forwards the message to everyone except the sender.

Each connected client is handled by a separate POSIX thread. This allows several users to chat simultaneously without blocking the server.

A mutex is used while accessing the shared client list. This prevents race conditions when multiple threads add or remove clients simultaneously.

💻 TCP Chat Client (client.c)

Each client connects to the server, enters a username, creates a separate thread to continuously receive incoming messages, and allows the user to send chat messages while receiving messages simultaneously. 


#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>
#include <pthread.h>

#define PORT 8080
#define BUFFER_SIZE 1024

int sockfd;

void *receiveMessage(void *arg)
{
    char message[BUFFER_SIZE];

    while(1)
    {
        int bytes = recv(sockfd,
                         message,
                         sizeof(message),
                         0);

        if(bytes <= 0)
            break;

        message[bytes] = '\0';

        printf("\n%s\n", message);

        printf("You : ");
        fflush(stdout);
    }

    return NULL;
}

int main()
{
    struct sockaddr_in server;

    char name[50];
    char message[BUFFER_SIZE];

    sockfd = socket(AF_INET,
                    SOCK_STREAM,
                    0);

    server.sin_family = AF_INET;
    server.sin_port = htons(PORT);
    inet_pton(AF_INET,
              "127.0.0.1",
              &server.sin_addr);

    connect(sockfd,
            (struct sockaddr *)&server,
            sizeof(server));

    printf("Enter Your Name : ");
    fgets(name,sizeof(name),stdin);

    name[strcspn(name,"\n")] = '\0';

    send(sockfd,
         name,
         strlen(name),
         0);

    pthread_t tid;

    pthread_create(&tid,
                   NULL,
                   receiveMessage,
                   NULL);

    while(1)
    {
        printf("You : ");

        fgets(message,
              sizeof(message),
              stdin);

        message[strcspn(message,"\n")] = '\0';

        if(strcmp(message,"exit")==0)
            break;

        send(sockfd,
             message,
             strlen(message),
             0);
    }

    close(sockfd);

    return 0;
}

🐞 Common Errors and Troubleshooting

Error 

bind(): Address already in use
Reason Another server is already using the same port.

Solution
  • Terminate the previous server process.
  • Use netstat -tulnp to identify the process.
  • Choose another port if required.

Reason The server is not running before the client starts.

Solution
  1. Run the server first.
  2. Then execute one or more client programs.

Compile using 

gcc server.c -o server -lpthread

gcc client.c -o client -lpthread

Possible reasons
  • Server not broadcasting correctly.
  • Client disconnected.
  • Firewall blocking the connection.
  • Wrong IP address or port number.

💡 Programming Tips

✔ Validate Connections

Always check the return values of socket(), bind(), listen(), accept(), and connect().

✔ Protect Shared Data

When multiple threads access the client list, use a mutex to avoid race conditions.

✔ Close Sockets

Close sockets properly after communication to avoid resource leaks.

🔄 Optional Implementation – Using fork()

Alternative Approach

The multi-user chat server can also be implemented using process-based concurrency with the fork() system call. The main implementation of this experiment uses POSIX threads (pthread). The fork() implementation is provided as an optional method to understand another approach to concurrent server programming.

Concept

In the thread-based implementation, the server creates a separate thread for each connected client. In the alternative implementation, the server creates a child process using fork() for each client.

⚠️ Important Difference

Threads belonging to the same process can directly access shared memory. However, a child process created using fork() has its own separate address space.

Therefore, the child processes cannot simply update a common clients[] array in the parent process.

For this reason, the optional fork-based implementation uses pipes for communication between child processes and the parent server.

Communication flow:

Child Process Pipe Parent Server Broadcast All Connected Clients

🖥️ Server Algorithm – fork() Method

  1. Start the server.
  2. Create a TCP socket using socket().
  3. Bind the socket to the specified port using bind().
  4. Put the socket into listening mode using listen().
  5. Initialize the client list.
  6. Wait for an incoming client connection.
  7. Accept the client using accept().
  8. Create a pipe for communication between the child and parent processes.
  9. Create a child process using fork().
  10. In the child process, communicate with the connected client.
  11. Receive the client's username and messages.
  12. Send received messages to the parent through the pipe.
  13. The parent receives messages from the child process.
  14. The parent broadcasts the message to connected clients.
  15. If a client disconnects, remove the client from the client list.
  16. The parent continues accepting new clients.
  17. Repeat the process until the server is terminated.
  18. Close the server socket and terminate the program.

👤 Client Algorithm

  1. Start the client.
  2. Create a TCP socket using socket().
  3. Specify the server IP address and port number.
  4. Connect to the server using connect().
  5. Enter a username.
  6. Send the username to the server.
  7. Create a receiving thread.
  8. Read messages from the keyboard.
  9. Send messages to the server using send().
  10. Receive messages from the server using recv().
  11. Display messages received from other clients.
  12. Continue communication until the user enters exit.
  13. Close the socket.
  14. Terminate the program.

💻 Server Program – fork() Version

Save the following program as server_fork.c. 



#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>
#include <sys/socket.h>
#include <sys/types.h>
#include <sys/wait.h>
#include <signal.h>

#define PORT 8080
#define BUFFER_SIZE 1024

void handle_client(int client_socket)
{
    char buffer[BUFFER_SIZE];

    while (1)
    {
        memset(buffer, 0, sizeof(buffer));

        int n = recv(client_socket,
                     buffer,
                     sizeof(buffer) - 1,
                     0);

        if (n <= 0)
            break;

        buffer[n] = '\0';

        if (strcmp(buffer, "exit") == 0)
            break;

        printf("Client [%d]: %s\n",
               getpid(),
               buffer);

        send(client_socket,
             buffer,
             strlen(buffer),
             0);
    }

    close(client_socket);
    exit(0);
}

void reap_children(int sig)
{
    while (waitpid(-1, NULL, WNOHANG) > 0);
}

int main()
{
    int server_socket;
    int client_socket;

    struct sockaddr_in server_addr;
    struct sockaddr_in client_addr;

    socklen_t client_len =
        sizeof(client_addr);

    signal(SIGCHLD, reap_children);

    server_socket =
        socket(AF_INET,
               SOCK_STREAM,
               0);

    if (server_socket < 0)
    {
        perror("socket");
        exit(1);
    }

    memset(&server_addr,
           0,
           sizeof(server_addr));

    server_addr.sin_family =
        AF_INET;

    server_addr.sin_addr.s_addr =
        INADDR_ANY;

    server_addr.sin_port =
        htons(PORT);

    if (bind(server_socket,
             (struct sockaddr *)&server_addr,
             sizeof(server_addr)) < 0)
    {
        perror("bind");
        exit(1);
    }

    listen(server_socket, 10);

    printf("TCP Server started\n");
    printf("Server PID: %d\n", getpid());
    printf("Port: %d\n", PORT);
    printf("Waiting for clients...\n");

    while (1)
    {
        client_socket =
            accept(server_socket,
                   (struct sockaddr *)&client_addr,
                   &client_len);

        if (client_socket < 0)
        {
            perror("accept");
            continue;
        }

        pid_t pid = fork();

        if (pid == 0)
        {
            close(server_socket);

            printf("Child process PID %d "
                   "handling client\n",
                   getpid());

            handle_client(client_socket);
        }

        else if (pid > 0)
        {
            close(client_socket);

            printf("Created child process "
                   "PID: %d\n",
                   pid);
        }

        else
        {
            perror("fork");
            close(client_socket);
        }
    }

    close(server_socket);

    return 0;
}
⚠️ Educational Note

The above simplified fork example demonstrates process-based concurrency. For a complete multi-user broadcast chat server, inter-process communication such as pipes or another IPC mechanism is required so that the parent can coordinate messages between different child processes.

Students should first understand the primary pthread-based multi-user chat implementation before attempting the fork-based approach.
