📘 What is a Raw Socket?

A Raw Socket is a special type of socket that allows an application to directly send and receive packets from the network layer without relying on higher-level transport protocols such as TCP or UDP.

Example
Packet analyzers such as Wireshark, tcpdump, and many intrusion detection systems use packet capturing techniques to inspect network traffic.

🚀 Why Use Raw Sockets?

Advantages
  • Direct access to network packets.
  • Capture incoming and outgoing packets.
  • Useful for protocol analysis.
  • Supports custom packet processing.
  • Helps understand packet structure.
  • Useful for network monitoring.
  • Foundation for packet sniffers.
Limitations
  • Requires administrator/root privileges.
  • Platform dependent.
  • Security restrictions apply.
  • More complex than TCP/UDP sockets.
  • Large traffic can overwhelm applications.

💻 Program – Packet Capturing using Raw Sockets

Objective

This program creates a Raw Socket to capture incoming IPv4 packets directly from the network interface. For every packet received, it extracts the IPv4 header and displays important information such as the packet length, source IP address, destination IP address, and protocol number.

Concepts Used
  • Raw Socket Programming
  • Packet Sniffing
  • IPv4 Header Processing
  • recvfrom()
  • Linux Networking APIs
packet_capture.c 

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>
#include <sys/socket.h>
#include <netinet/ip.h>
#include <linux/if_packet.h>
#include <net/ethernet.h>

#define BUFFER_SIZE 65536

int main()
{
    int sockfd;
    unsigned char *buffer;
    struct sockaddr saddr;
    socklen_t saddr_len;

    struct iphdr *ip_header;

    buffer = (unsigned char *)malloc(BUFFER_SIZE);

    if(buffer == NULL)
    {
        printf("Memory Allocation Failed\n");
        return 1;
    }

    /* Create Raw Socket */
    sockfd = socket(AF_PACKET, SOCK_RAW, htons(ETH_P_ALL));

    if(sockfd < 0)
    {
        perror("Socket");
        return 1;
    }

    printf("\n=========================================\n");
    printf("   RAW SOCKET PACKET CAPTURE STARTED\n");
    printf("=========================================\n");

    while(1)
    {
        saddr_len = sizeof(saddr);

        int packet_size = recvfrom(sockfd,
                                   buffer,
                                   BUFFER_SIZE,
                                   0,
                                   &saddr,
                                   &saddr_len);

        if(packet_size < 0)
        {
            perror("recvfrom");
            break;
        }

        ip_header = (struct iphdr *)buffer;

        struct sockaddr_in source;
        struct sockaddr_in destination;

        memset(&source,0,sizeof(source));
        memset(&destination,0,sizeof(destination));

        source.sin_addr.s_addr = ip_header->saddr;
        destination.sin_addr.s_addr = ip_header->daddr;

        printf("\n----------------------------------------\n");

        printf("Packet Length      : %d Bytes\n",packet_size);

        printf("IP Version         : %d\n",
               ip_header->version);

        printf("Header Length      : %d Bytes\n",
               ip_header->ihl * 4);

        printf("TTL                : %d\n",
               ip_header->ttl);

        printf("Protocol Number    : %d\n",
               ip_header->protocol);

        printf("Source IP          : %s\n",
               inet_ntoa(source.sin_addr));

        printf("Destination IP     : %s\n",
               inet_ntoa(destination.sin_addr));

        printf("----------------------------------------\n");
    }

    close(sockfd);

    free(buffer);

    return 0;
}

📖 Program Explanation

The socket is created using 

socket(AF_INET,
SOCK_RAW,
IPPROTO_TCP);
This allows the program to receive raw TCP packets directly from the Network Layer.

The program continuously waits for packets using 

recvfrom()
Whenever a packet arrives, it is copied into a packet buffer.

The received buffer is typecast into an iphdr structure. This allows easy access to Version, Header Length, TTL, Protocol, Source IP, and Destination IP.

The program prints:
  • Packet Length
  • IP Version
  • Header Length
  • TTL
  • Protocol Number
  • Source IP Address
  • Destination IP Address
