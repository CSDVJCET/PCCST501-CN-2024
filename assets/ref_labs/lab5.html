Aim

The objective of this laboratory is to understand the fundamental concepts of socket programming before implementing network applications. Students will study client–server communication, TCP/IP protocol architecture, socket APIs, Linux networking commands, byte ordering and address conversion techniques.

Learning Outcomes

  • Explain Socket Programming.
  • Understand Client–Server Communication.
  • Differentiate TCP and UDP.
  • Identify Socket Types.
  • Understand Socket APIs.
  • Use Linux Networking Commands.
  • Understand Byte Ordering.
  • Prepare for Programming Experiments.
