📂 What is a File Server?

A File Server is a computer that stores files and provides them to clients over a network. Instead of storing every file locally, users request files from the server whenever needed.

Example
Imagine requesting notes.txt from your college server. If the file exists, ✅ the server sends its contents. Otherwise, ❌ the server returns "File Not Found".

🚀 Why a Concurrent File Server?

Advantages
  • Serves multiple users simultaneously.
  • Reduces client waiting time.
  • Improves server performance.
  • Efficient CPU utilization.
  • Scalable for large networks.
  • Reliable communication using TCP.
  • Supports large file transfer.
Challenges
  • Requires thread management.
  • Higher memory usage.
  • Synchronization issues.
  • Proper error handling required.
  • Resource cleanup is important.

🏗️ Concurrent File Server Architecture

The Concurrent File Server follows the Client–Server Architecture. A client sends the name of a required file to the server. The server creates a separate worker thread for each client, searches for the requested file, and sends either the file contents or an appropriate error message along with its Process ID (PID).

🧵 Why Multithreading?

If only one client is served at a time, other clients must wait until the current request is completed. A concurrent server creates a separate worker thread for each client, allowing multiple file requests to be processed simultaneously.

Benefits
  • Supports multiple clients simultaneously.
  • Improves server responsiveness.
  • Reduces waiting time.
  • Better CPU utilization.
  • Represents real-world file servers.

🧪 Experiment

Aim

To implement a Concurrent File Server using TCP Socket Programming. The client sends the name of a file to the server. The server searches for the requested file and, if it exists, sends the file contents along with its Process ID (PID). Otherwise, it sends an appropriate error message together with its PID.

Problem Statement

Develop a concurrent TCP File Server capable of serving multiple clients simultaneously. Each client requests a filename. The server receives the filename, creates a worker thread, searches the current directory, and sends either the requested file contents or a "File Not Found" message. The response must also include the Server Process ID (PID).

Expected Output
  • Client successfully connects to the server.
  • Filename reaches the server.
  • Server searches the requested file.
  • If found, file contents are transmitted.
  • If not found, an error message is transmitted.
  • PID is displayed with every response.

📋 Functional Requirements

Server Requirements

  • Receive the requested filename.
  • Search the requested file.
  • Obtain the Server PID.
  • Send PID with file contents.
  • Send PID with "File Not Found" if unavailable.

🖥️ Server Algorithm

  1. Create a TCP socket.
  2. Bind the socket to a predefined port.
  3. Start listening for incoming connections.
  4. Accept a client connection.
  5. Create a worker thread.
  6. Receive the requested filename.
  7. Search the file in the current directory.
  8. Retrieve the server Process ID using getpid().
  9. If file exists, send PID and file contents.
  10. Otherwise send PID and "File Not Found".
  11. Close client connection.
  12. Continue serving new clients.

🖥️ Program 1 – Concurrent TCP File Server

Objective

The server waits for client connections. Whenever a client connects, the server creates a separate worker thread. The worker thread receives the filename, searches the requested file, retrieves the server Process ID (PID), and sends either the file contents or an appropriate error message to the client.

Concepts Used
  • TCP Socket Programming
  • POSIX Threads (pthread)
  • Concurrent Client Handling
  • Linux File Handling
  • Process ID (PID)
  • Reliable Data Transfer
server.c 

#include

#include

#define PORT 8080
#define BUFFER_SIZE 1024

void *handleClient(void *arg)
{
    int clientSocket = *(int *)arg;

    free(arg);

    char filename[100];
    char buffer[BUFFER_SIZE];
    FILE *fp;

    memset(filename,0,sizeof(filename));

    recv(clientSocket,
         filename,
         sizeof(filename),
         0);

    printf("\nClient Requested : %s\n",
           filename);

    fp = fopen(filename,"r");

    sprintf(buffer,
            "\nServer PID : %d\n\n",
            getpid());

    send(clientSocket,
         buffer,
         strlen(buffer),
         0);

    if(fp == NULL)
    {
        strcpy(buffer,
        "File Not Found!");

        send(clientSocket,
             buffer,
             strlen(buffer),
             0);
    }
    else
    {
        while(fgets(buffer,
                    BUFFER_SIZE,
                    fp)!=NULL)
        {
            send(clientSocket,
                 buffer,
                 strlen(buffer),
                 0);
        }

        fclose(fp);
    }

    close(clientSocket);

    printf("Client Served Successfully.\n");

    pthread_exit(NULL);
}

int main()
{
    int serverSocket;
    int *clientSocket;

    struct sockaddr_in serverAddr;
    struct sockaddr_in clientAddr;

    socklen_t addrSize;

    pthread_t tid;

    serverSocket =
    socket(AF_INET,
           SOCK_STREAM,
           0);

    if(serverSocket<0)
    {
        perror("Socket Error");
        exit(1);
    }

    serverAddr.sin_family=AF_INET;
    serverAddr.sin_port=htons(PORT);
    serverAddr.sin_addr.s_addr=INADDR_ANY;

    bind(serverSocket,
         (struct sockaddr*)&serverAddr,
         sizeof(serverAddr));

    listen(serverSocket,5);

    printf("\n=================================\n");
    printf(" Concurrent File Server Started\n");
    printf("=================================\n");
    printf("Listening on Port %d\n",PORT);

    while(1)
    {
        addrSize=sizeof(clientAddr);

        clientSocket=
        malloc(sizeof(int));

        *clientSocket=
        accept(serverSocket,
               (struct sockaddr*)&clientAddr,
               &addrSize);

        printf("\nClient Connected...\n");

        pthread_create(&tid,
                       NULL,
                       handleClient,
                       clientSocket);

        pthread_detach(tid);
    }

    close(serverSocket);

    return 0;
}

💻 Program 2 – TCP File Client

Objective

The client connects to the Concurrent File Server, sends the required filename, receives the server Process ID (PID) along with the requested file contents (or an error message), and displays the received response.

Concepts Used
  • TCP Client Socket
  • Reliable Communication
  • Filename Transmission
  • Receiving File Contents
  • Displaying Server PID
client.c 

#include
#include
#include
#include
#include

#define PORT 8080
#define BUFFER_SIZE 1024

int main()
{
    int clientSocket;

    struct sockaddr_in serverAddr;

    char filename[100];
    char buffer[BUFFER_SIZE];

    clientSocket =
    socket(AF_INET,
           SOCK_STREAM,
           0);

    if(clientSocket < 0)
    {
        perror("Socket Error");
        exit(1);
    }

    serverAddr.sin_family = AF_INET;
    serverAddr.sin_port = htons(PORT);
    serverAddr.sin_addr.s_addr =
    inet_addr("127.0.0.1");

    if(connect(clientSocket,
              (struct sockaddr *)&serverAddr,
              sizeof(serverAddr)) < 0)
    {
        perror("Connection Failed");
        exit(1);
    }

    printf("Enter Filename : ");

    scanf("%s",filename);

    send(clientSocket,
         filename,
         strlen(filename),
         0);

    printf("\n");

    while(1)
    {
        int bytes =
        recv(clientSocket,
             buffer,
             BUFFER_SIZE-1,
             0);

        if(bytes <= 0)
            break;

        buffer[bytes]='\0';

        printf("%s",buffer);
    }

    close(clientSocket);

    return 0;
}
