Imagine playing PUBG, BGMI, Valorant, making a video call, or asking Google DNS for the IP address of a website.

🌐 What is UDP?

UDP (User Datagram Protocol) is a connectionless transport-layer protocol. Unlike TCP, UDP does not establish a connection before transmitting data. Each message is sent independently as a datagram.

Simple Definition

UDP sends independent packets called datagrams without creating a dedicated connection between the client and the server.

🖥 UDP Client–Server Architecture

Unlike TCP, UDP does not establish a connection before communication. The client simply sends a datagram to the server, and the server receives it. There is no connection setup or teardown.

Every message is independent. The server does not know whether previous messages were delivered.

💻 UDP Socket Programming APIs

A UDP application communicates using operating-system socket APIs. Unlike TCP, UDP does not use listen(), accept(), or connect(). Instead, applications exchange datagrams using sendto() and recvfrom().

① socket()

Purpose

Creates a UDP communication endpoint. This is the first function used in every UDP program.

Syntax

int socket(int domain,
           int type,
           int protocol);

Parameters

Parameter Description
domain AF_INET (IPv4)
type SOCK_DGRAM (UDP)
protocol Normally 0
Returns a socket descriptor. Returns -1 if socket creation fails.

② bind()

Purpose

Associates a UDP socket with an IP address and port number. Normally only the server performs this operation.

Syntax

bind(sockfd,
     (struct sockaddr *)&server,
     sizeof(server));
Think of bind() as assigning a postal address. Clients know where to send UDP datagrams because the server has a fixed address.

③ sendto()

Purpose

Sends a UDP datagram to a specified destination. Unlike TCP, no connection is established before sending.

Syntax

sendto(sockfd,
       buffer,
       strlen(buffer),
       0,
       (struct sockaddr *)&server,
       sizeof(server));
The destination IP address and port number are supplied every time a datagram is transmitted.

④ recvfrom()

Purpose

Receives a UDP datagram from any sender. The function also returns the sender's address.

Syntax

recvfrom(sockfd,
         buffer,
         sizeof(buffer),
         0,
         (struct sockaddr *)&client,
         &addrSize);
Unlike TCP's recv(), recvfrom() tells us who sent the datagram.

⑤ close()

Purpose

Releases the UDP socket and frees operating system resources.

Syntax

close(sockfd);
Always close sockets after communication completes.

💡 Tip: The UDP server simply waits for incoming datagrams using recvfrom(). The client sends data using sendto(), the server processes the request, and replies with another sendto(). No connection establishment is required.

🎯 API Summary

Function Used By Purpose
socket() Client & Server Create UDP socket
bind() Server Assign IP & Port
sendto() Client & Server Send datagram
recvfrom() Client & Server Receive datagram
close() Client & Server Release socket
Remember the UDP order!

Server: socket → bind → recvfrom → process → sendto → close

Client: socket → sendto → recvfrom → close

🖥 Simple UDP Server

The server waits for a UDP datagram from any client. After receiving the message, it immediately replies with Hello Client. 

#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>

int main()
{
    int sockfd;

    char buffer[100];

    struct sockaddr_in server, client;

    socklen_t len;

    sockfd = socket(AF_INET,
                    SOCK_DGRAM,
                    0);

    server.sin_family = AF_INET;
    server.sin_port = htons(5000);
    server.sin_addr.s_addr = INADDR_ANY;

    bind(sockfd,
         (struct sockaddr *)&server,
         sizeof(server));

    len = sizeof(client);

    recvfrom(sockfd,
             buffer,
             sizeof(buffer),
             0,
             (struct sockaddr *)&client,
             &len);

    printf("Client : %s\n", buffer);

    strcpy(buffer,
           "Hello Client");

    sendto(sockfd,
           buffer,
           strlen(buffer)+1,
           0,
           (struct sockaddr *)&client,
           len);

    close(sockfd);

    return 0;
}

📄 Problem Statement

Develop a UDP client-server application in C. The client accepts an Internet chat abbreviation from the keyboard and sends it to the server. The server compares the received abbreviation with its predefined dictionary and returns the corresponding expanded English meaning. If the abbreviation is not found, the server should return an appropriate message.

🖥 Server Algorithm

  1. Create a UDP socket.
  2. Bind the socket to a port number.
  3. Wait for a datagram using recvfrom().
  4. Compare the received abbreviation with the dictionary.
  5. If found, retrieve its meaning.
  6. Otherwise return "Abbreviation Not Found".
  7. Send the result back using sendto().
  8. Close the socket.

👤 Client Algorithm

  1. Create a UDP socket.
  2. Read the abbreviation from the keyboard.
  3. Send the abbreviation to the server.
  4. Receive the translated meaning.
  5. Display the received message.
  6. Close the socket.

🖥 Complete UDP Translator Server

The UDP server receives an abbreviation from the client, searches for its meaning, and sends the expanded text back to the client. 

#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include <unistd.h>
#include <arpa/inet.h>

#define PORT 5000

int main()
{
    int sockfd;
    char buffer[100];
    char reply[100];

    struct sockaddr_in server, client;
    socklen_t len;

    sockfd = socket(AF_INET,
                    SOCK_DGRAM,
                    0);

    if(sockfd < 0)
    {
        printf("Socket creation failed\n");
        exit(1);
    }

    server.sin_family = AF_INET;
    server.sin_addr.s_addr = INADDR_ANY;
    server.sin_port = htons(PORT);

    bind(sockfd,
         (struct sockaddr *)&server,
         sizeof(server));

    printf("UDP Server Started...\n");

    len = sizeof(client);

    while(1)
    {
        recvfrom(sockfd,
                 buffer,
                 sizeof(buffer),
                 0,
                 (struct sockaddr *)&client,
                 &len);

        printf("Received : %s\n",buffer);

        if(strcmp(buffer,"LOL")==0)
            strcpy(reply,"Laughing Out Loud");

        else if(strcmp(buffer,"BRB")==0)
            strcpy(reply,"Be Right Back");

        else if(strcmp(buffer,"OMG")==0)
            strcpy(reply,"Oh My God");

        else if(strcmp(buffer,"IDK")==0)
            strcpy(reply,"I Don't Know");

        else if(strcmp(buffer,"TTYL")==0)
            strcpy(reply,"Talk To You Later");

        else if(strcmp(buffer,"ASAP")==0)
            strcpy(reply,"As Soon As Possible");

        else if(strcmp(buffer,"FYI")==0)
            strcpy(reply,"For Your Information");

        else if(strcmp(buffer,"IMO")==0)
            strcpy(reply,"In My Opinion");

        else if(strcmp(buffer,"GTG")==0)
            strcpy(reply,"Got To Go");

        else if(strcmp(buffer,"NP")==0)
            strcpy(reply,"No Problem");

        else
            strcpy(reply,"Abbreviation Not Found");

        sendto(sockfd,
               reply,
               strlen(reply)+1,
               0,
               (struct sockaddr *)&client,
               len);

        printf("Reply Sent\n\n");
    }

    close(sockfd);

    return 0;
}

👤 Complete UDP Translator Client

The client accepts a chat abbreviation from the user, sends it to the UDP server, and displays the translated response.

#include <string.h>

#include <unistd.h>
#include <arpa/inet.h>

{
    int sockfd;

    char buffer[100];

    struct sockaddr_in server;

    socklen_t len;

    sockfd = socket(AF_INET,
                    SOCK_DGRAM,
                    0);

    if(sockfd < 0)
    {
        printf("Socket creation failed\n");
        exit(1);
    }

    server.sin_family = AF_INET;
    server.sin_port = htons(PORT);
    server.sin_addr.s_addr =
            inet_addr("127.0.0.1");

    scanf("%s",buffer);

           (struct sockaddr *)&server,

             buffer,
             sizeof(buffer),
             0,
             (struct sockaddr *)&server,
             &len);

    close(sockfd);

    return 0;
}

Error Reason Solution
Socket creation failed Unable to create socket Check the socket() parameters
bind() failed Port already in use Choose another port or terminate the existing process
No response from server Server not running Start the server before running the client

💡 Programming Tips

  • Always check the return value of socket().
  • Verify that bind() succeeds.
  • Initialize structures before use.
  • Close sockets after communication.
  • Use meaningful variable names.
  • Validate user input.
  • Use adequate buffer sizes.
  • Display informative error messages.
  • Test with multiple abbreviations.
  • Comment your program.
