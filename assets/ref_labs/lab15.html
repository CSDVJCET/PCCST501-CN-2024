🎯 Aim

To configure an Extended ACL so that only Host_B is allowed to communicate with the network 172.16.10.0/24, while access from Lab_B and Lab_C is denied.

📚 Extended ACL Concept

An extended IP ACL can match traffic using source and destination information. In this experiment, ACL 101 distinguishes the permitted Host_B address from the rest of the 172.16.30.0/24 source network.

Permit

172.16.30.10 → 172.16.10.0/24

Deny

172.16.30.0/24 → 172.16.10.0/24

Permit

Other IP traffic → allowed by the final permit statement

📝 Procedure

Step 1 – Build Figure 2

Recreate the prescribed topology in Cisco Packet Tracer.

Step 2 – Configure IP addressing

Configure Host_A, Host_B, Lab_B and Lab_C with the addresses specified in the manual and configure the router interfaces.

Step 3 – Test the original connectivity

Verify that the hosts can communicate before applying the ACL.

Step 4 – Create Extended ACL 101

Permit Host_B, deny the remaining 172.16.30.0/24 sources to the 172.16.10.0/24 destination network, then permit other IP traffic.

Step 5 – Apply the ACL

Apply ACL 101 inbound on the interface connected to the 172.16.30.0 network.

Step 6 – Display the ACL

Use show access-lists and verify the sequence entries.

Step 7 – Perform the three connectivity tests

Ping Host_A from Host_B, Lab_B and Lab_C and record the results.

⌨️ ACL Configuration

Router(config)# access-list 101 permit ip host 172.16.30.10 172.16.10.0 0.0.0.255
Router(config)# access-list 101 deny ip 172.16.30.0 0.0.0.255 172.16.10.0 0.0.0.255
Router(config)# access-list 101 permit ip any any
