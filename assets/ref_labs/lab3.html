📧 Lab 3: SMTP Mail Detective

Follow one e-mail from client to mail server and reconstruct the SMTP conversation using packet evidence.

Experiment03
ProtocolSMTP
ToolWireshark
EvidenceMail Case File

🎯 Aim

To capture and analyse SMTP traffic, identify client and server endpoints and ports, interpret SMTP commands and response codes, and inspect the Internet Message Format (IMF) content carried during mail transfer when visible.

⚠️ Important Lab Reality

Modern e-mail services usually encrypt SMTP traffic using TLS. With Gmail, Outlook and many other services, the filter smtp may show no readable commands or message content.

Perform this experiment only with the instructor-approved lab mail setup or a controlled SMTP environment where the required educational traffic is intentionally observable. Do not disable security on a personal e-mail account, and do not capture other users' traffic.

🕵️ Investigation Tasks

(a) Identify the Two Hosts

Inspect the source and destination IP addresses appearing in the SMTP packets.

  • Which IP address belongs to your computer?
  • What host or mail server does the other IP address represent?
(b) Find the SMTP Client Port

Record the two port numbers. Identify the temporary port used by the SMTP client process and state the range/category to which it belongs.

Client port = __________________ Port range/category = __________________
(c) Find the SMTP Server Port

Record the destination/server port used in your approved lab setup.

SMTP server port = __________________
(d) Decode the SMTP Conversation

Examine every visible SMTP command and server response code. Record each one and explain its meaning.

Possible examples may include:

EHLO / HELOMAIL FROMRCPT TO DATAQUIT220 250354221

Record only what actually appears in your capture.

(e) Inspect the IMF Message

Locate the Internet Message Format content encapsulated in the SMTP data transfer, if visible. Identify the message headers and body.

From: To: Subject: Date: Message body:

If encryption prevents inspection, record Not visible because the SMTP session is encrypted.

🏁 Final Challenge

Reconstruct the Mail Journey

Write a short sequence showing how the message travelled:

My computer (IP : client port) ↓ SMTP command / response exchange ↓ Mail server (IP : server port) ↓ IMF message content

Support the sequence with packet numbers from your own capture.

❓ Viva Questions

  1. What is the role of SMTP?
  2. How do you identify the client and server from IP addresses and ports?
  3. Why does a client usually use a temporary port?
  4. What is the purpose of EHLO or HELO?
  5. What do MAIL FROM and RCPT TO represent?
  6. What happens after the DATA command?
  7. What is an SMTP response code?
  8. What is IMF?
  9. How is IMF related to SMTP?
  10. Why may modern SMTP content be unreadable in Wireshark?
