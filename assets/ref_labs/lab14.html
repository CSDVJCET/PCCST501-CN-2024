🌐 Lab 14
OSPF Routing

Implement OSPF routing for the network shown in Figure 1, display the routing table, and verify connectivity using ping.

Start Experiment Commands

OSPF

Link-state routing protocol

Area 0

Single OSPF area used in the experiment

Routing Table

Identify OSPF-learned routes

Ping

Verify end-to-end connectivity

🎯 Aim

To configure OSPF (Open Shortest Path First) routing on the routers in the given network topology and verify connectivity using the routing table and ping commands.

📚 About OSPF

OSPF is a link-state routing protocol. In this experiment, the routers participate in Area 0 and advertise their connected networks using OSPF.

Process ID
The experiment uses router ospf 1.
Area
All specified networks are advertised in area 0.
Verification
Use show ip ospf neighbor, show ip route, and ping.

🧰 Requirements

  • Cisco Packet Tracer
  • Routers corresponding to the prescribed topology
  • Appropriate router interfaces and connections
  • IPv4 addresses as specified in the network topology
  • /24 addressing for the listed networks

📝 Procedure

Step 1 – Build the topology

Recreate the network shown in Figure 1 in Cisco Packet Tracer.

Step 2 – Configure IP addresses

Configure the router interfaces using the addresses assigned to the networks in the topology.

Step 3 – Enable interfaces

Use no shutdown and verify that the required interfaces are operational.

Step 4 – Configure OSPF

Enter OSPF process 1 and advertise each participating network in area 0.

Step 5 – Verify neighbor relationships

Use show ip ospf neighbor and check that OSPF adjacency has been established.

Step 6 – Display the routing table

Use show ip route and identify routes marked O.

Step 7 – Verify connectivity

Use ping between the specified routers/networks.
