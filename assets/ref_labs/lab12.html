📚 What is Static Routing?

Static routing means that the network administrator manually adds routes to a router's routing table. Unlike dynamic routing protocols, the route is not learned automatically from another routing protocol.

Destination network
The remote network that must be reached.
Subnet mask
Identifies the size of the destination network.
Next hop
The next router/interface through which the packet should be forwarded.

📝 Procedure

Step 1 – Build the topology

Open Cisco Packet Tracer and create the router topology shown in Figure 1. Connect the interfaces exactly as specified.

Step 2 – Configure interface addresses

Assign each interface its address from Figure 1 and use the /24 subnet mask.

Step 3 – Enable interfaces

Enter interface configuration mode and use no shutdown. Verify the interface status.

Step 4 – Add static routes

On each router, add routes for remote networks that are not already directly connected.

Step 5 – Display the routing table

Use show ip route and identify the static routes.

Step 6 – Verify connectivity

Use ping between appropriate hosts/interfaces and confirm successful end-to-end communication.

⌨️ Static Routing Commands

Router> enable
Router# configure terminal
Router(config)#

Router(config)# interface fastEthernet 0/0
Router(config-if)# ip address <IP-ADDRESS> 255.255.255.0
Router(config-if)# no shutdown

Use the interface name and IP address given in Figure 1.

The general Cisco IOS syntax is:

Router(config)# ip route <destination-network> <subnet-mask> <next-hop-IP>

For example, the structure is:

ip route 172.16.X.0 255.255.255.0 <NEXT-HOP-IP>

Do not use the example address as a replacement for the addressing in Figure 1. Enter the actual destination network and next-hop address specified by the prescribed topology.

Router# show ip route

Look for entries marked S, which identify static IPv4 routes.

Router# show ip interface brief

Check that required interfaces have the expected IP addresses and are operational.

Router# ping <destination-IP>

In Packet Tracer, you can also use the PC command prompt:

PC> ping <destination-IP>

Router# copy running-config startup-config
