🕒 What is a Time Server?

A Time Server is a network application that provides the current date and time to requesting clients. When a client sends a request, the server immediately retrieves its current system time and sends it back to the client.

Key Idea

Unlike connection-oriented applications, a UDP Time Server simply waits for incoming datagrams, processes each request independently, and returns the current system time.

📡 Why UDP for a Time Server?

Advantages
  • Connectionless communication
  • Very low overhead
  • Fast request-response service
  • No connection establishment delay
  • Suitable for lightweight applications
  • Simple implementation
  • Efficient for time queries
Limitations
  • No guaranteed delivery
  • Packets may be lost
  • No ordering guarantee
  • No retransmission mechanism
  • No congestion control

🚀 Concurrent UDP Time Server

A normal UDP server processes one request at a time. In this experiment, the server is designed as a Concurrent UDP Time Server. Whenever a client request arrives, the server creates a separate worker thread to process that request while continuing to listen for additional clients.

Advantages
  • Supports multiple clients simultaneously.
  • Reduces waiting time.
  • Improves responsiveness.
  • Efficient utilization of CPU resources.
  • Represents real-world network server design.

🖥️ Program 1 – Concurrent UDP Time Server

Objective

The UDP Time Server waits for requests from clients. Whenever a request arrives, the server creates a worker thread that retrieves the current system time and sends it back to the requesting client. Meanwhile, the main thread immediately returns to listening for additional requests.

Concepts Used
  • UDP Socket Programming
  • Datagram Communication
  • POSIX Threads (pthread)
  • Concurrent Request Handling
  • System Time Functions
  • Linux Socket APIs
server.c 

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>
#include <pthread.h>
#include <time.h>

#define PORT 8080
#define BUFFER_SIZE 1024

typedef struct
{
    int serverSocket;
    struct sockaddr_in clientAddr;
    socklen_t clientLen;
    char request[BUFFER_SIZE];
} ClientRequest;

void *handleClient(void *arg)
{
    ClientRequest *client = (ClientRequest *)arg;

    time_t currentTime;
    char *timeString;

    time(¤tTime);
    timeString = ctime(¤tTime);

    sendto(client->serverSocket,
           timeString,
           strlen(timeString),
           0,
           (struct sockaddr *)&client->clientAddr,
           client->clientLen);

    printf("-------------------------------------\n");
    printf("Request received from %s:%d\n",
           inet_ntoa(client->clientAddr.sin_addr),
           ntohs(client->clientAddr.sin_port));

    printf("Time Sent : %s", timeString);

    free(client);

    pthread_exit(NULL);
}

int main()
{
    int serverSocket;

    struct sockaddr_in serverAddr;
    struct sockaddr_in clientAddr;

    socklen_t clientLen;

    char buffer[BUFFER_SIZE];

    pthread_t tid;

    serverSocket = socket(AF_INET, SOCK_DGRAM, 0);

    if(serverSocket < 0)
    {
        perror("Socket Creation Failed");
        exit(EXIT_FAILURE);
    }

    memset(&serverAddr,0,sizeof(serverAddr));

    serverAddr.sin_family = AF_INET;
    serverAddr.sin_addr.s_addr = INADDR_ANY;
    serverAddr.sin_port = htons(PORT);

    if(bind(serverSocket,
            (struct sockaddr *)&serverAddr,
            sizeof(serverAddr)) < 0)
    {
        perror("Bind Failed");
        close(serverSocket);
        exit(EXIT_FAILURE);
    }

    printf("\n=====================================\n");
    printf(" Concurrent UDP Time Server\n");
    printf("=====================================\n");
    printf("Listening on Port %d...\n\n",PORT);

    while(1)
    {
        ClientRequest *client =
            (ClientRequest *)malloc(sizeof(ClientRequest));

        client->serverSocket = serverSocket;

        client->clientLen = sizeof(client->clientAddr);

        int bytes = recvfrom(serverSocket,
                             client->request,
                             BUFFER_SIZE,
                             0,
                             (struct sockaddr *)&client->clientAddr,
                             &client->clientLen);

        if(bytes < 0)
        {
            perror("Receive Failed");
            free(client);
            continue;
        }

        client->request[bytes] = '\0';

        pthread_create(&tid,
                       NULL,
                       handleClient,
                       client);

        pthread_detach(tid);
    }

    close(serverSocket);

    return 0;
}

Binding associates the socket with a port number so that clients know where to send their requests.

Without bind(), the server cannot receive datagrams on a known port.

buffer,
BUFFER_SIZE,
0,
(struct sockaddr *)&clientAddr,
&clientLen);

The server waits until a client sends a request. Once a datagram arrives, recvfrom() stores both the message and the sender's address. 


pthread_create(&tid,
NULL,
handleClient,
client);

A new worker thread is created for every client request. The main thread immediately goes back to waiting for more incoming requests.

This allows the server to handle multiple clients without blocking future requests.

The time() function retrieves the current system timestamp. The ctime() function converts it into a readable date and time string.

The formatted system time is transmitted back to the requesting client.

The server continuously waits for new requests inside an infinite loop. After serving one client, it immediately becomes ready for the next request.

Objective

The client creates a UDP socket and sends a simple request message to the server. The server replies with its current system time. The client then displays the received time on the screen.

#define PORT 8080
#define BUFFER_SIZE 1024

int main()
{
    int clientSocket;

    struct sockaddr_in serverAddr;

    char request[] = "TIME";

    char buffer[BUFFER_SIZE];

    socklen_t len = sizeof(serverAddr);

    clientSocket = socket(AF_INET, SOCK_DGRAM, 0);

    if(clientSocket < 0)
    {
        perror("Socket Creation Failed");
        exit(EXIT_FAILURE);
    }

    memset(&serverAddr,0,sizeof(serverAddr));

    serverAddr.sin_family = AF_INET;
    serverAddr.sin_port = htons(PORT);
    serverAddr.sin_addr.s_addr = inet_addr("127.0.0.1");

    sendto(clientSocket,
           request,
           strlen(request),
           0,
           (struct sockaddr *)&serverAddr,
           len);

    int bytes = recvfrom(clientSocket,
                         buffer,
                         BUFFER_SIZE,
                         0,
                         NULL,
                         NULL);

    if(bytes < 0)
    {
        perror("Receive Failed");
        close(clientSocket);
        exit(EXIT_FAILURE);
    }

    buffer[bytes]='\0';

    printf("\n=====================================\n");
    printf(" Current Time Received from Server\n");
    printf("=====================================\n\n");

    printf("%s\n",buffer);

    close(clientSocket);

    return 0;
}

💡 Programming Tips

  • Always check the return value of socket().
  • Always bind the server socket before receiving data.
  • Use htons() when specifying the port number.
  • Close sockets before exiting.
  • Use pthread_detach() for worker threads.
  • Display meaningful error messages using perror().
  • Validate IP addresses before sending requests.
