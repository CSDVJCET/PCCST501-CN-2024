🎯 Aim

As the network administrator, configure the network so that students in the CCF subnet cannot access the hackathon website hosted at 140.80.120.7.

The server provides services other than web hosting, so the ACL must block only HTTP access; other services should remain available. This is the stated requirement of Experiment 16. fileciteturn34file0

📖 Problem Statement

You are the network administrator of your college. The college has been assigned the network address 140.80.0.0. There are 20 subnets. The Central Computing Facility (CCF) is located in the 4th subnet. A hackathon website is hosted on a server assigned the 7th host address in the 16th subnet.

Requirement: Block students from CCF from accessing the hackathon website, but do not block other services provided by the same server. fileciteturn34file1

🧮 Step 1 – Subnetting

Given
  • Network: 140.80.0.0
  • Class: Class B
  • Default mask: /16
  • Required subnets: 20
Borrow bits

We need the smallest number of borrowed bits satisfying:

2⁵ = 32 ≥ 20

Therefore, borrow 5 bits from the host portion.

New prefix
/16 + 5 = /21
Subnet mask
255.255.248.0
Block size
256 − 248 = 8

The manual therefore uses the /21 subnet mask and a wildcard mask of 0.0.7.255. fileciteturn35file7

🧠 Why an Extended ACL?

The requirement is not to block the server completely. Only the web service must be denied. Therefore, the ACL needs to match:

  • Source: 140.80.24.0/21
  • Protocol: TCP
  • Destination: host 140.80.120.7
  • Destination port: 80 (HTTP)

This is why the ACL entry uses deny tcp ... eq 80. fileciteturn36file0

⌨️ Step 4 – Configure Extended ACL

Router(config)# access-list 101 deny tcp 140.80.24.0 0.0.7.255 host 140.80.120.7 eq 80
Router(config)# access-list 101 permit ip any any

The manual specifies the deny statement for HTTP and then the final permit statement so that other traffic is not denied. fileciteturn36file0

Router(config)# interface GigabitEthernet0/0
Router(config-if)# ip access-group 101 in

The manual applies ACL 101 inbound on the router interface connected to the CCF subnet. fileciteturn36file2

Router# show access-lists

Check that ACL 101 contains the HTTP deny rule and the general permit rule.

Router# show ip interface GigabitEthernet0/0

Confirm that the access list is applied in the required inbound direction.

📝 Procedure

Step 1

Recreate the required network topology in Cisco Packet Tracer.

Step 2

Configure the college network address 140.80.0.0 and subnet it into at least 20 subnets.

Step 3

Use 255.255.248.0 (/21) as the subnet mask.

Step 4

Identify the 4th subnet as CCF: 140.80.24.0/21.

Step 5

Identify the 16th subnet as 140.80.120.0/21 and the server as 140.80.120.7.

Step 6

Configure ACL 101 to deny TCP port 80 traffic from CCF to the server.

Step 7

Add permit ip any any so other services are not denied.

Step 8

Apply ACL 101 inbound on the CCF-facing interface and verify HTTP and other services.
