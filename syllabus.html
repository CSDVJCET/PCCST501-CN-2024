PCCST501 Computer Networks — Course Syllabus

Semester S5 • Common to CS, CD, CM, CR, CA, AD, AI, CB, CN, CU, CI • Credits: 4 (L-T-P: 3-1-0)

View Official Syllabus PDF

Course Objectives

  1. To introduce the core concepts of computer networking and protocol layering.
  2. To develop a big picture of internetworking implementation on Linux-based systems.
  3. To impart an overview of network management and physical transmission concepts.

Course Outcomes (COs) & Bloom's Taxonomy

CO Code Course Outcome Description Bloom's Knowledge Level (KL)
CO1 Understand the internetworking design in terms of protocol stack and the role of various application layer protocols. K2 (Understand)
CO2 Illustrate the functions of the transport layer from connectionless and connection-oriented perspectives. K3 (Apply)
CO3 Identify how the network layer achieves host-to-host connectivity and caters to the diverse service requirements of host applications. K3 (Apply)
CO4 Explain the nuances of the data link layer design and demonstrate the various data link layer protocols. K3 (Apply)
CO5 Describe the fundamental characteristics of the physical layer and understand how the physical layer supports top layers. K2 (Understand)

Module-Wise Syllabus & Contact Hours

Module Syllabus Topics & Hands-On Focus Contact Hours
Module 1 Overview of the Internet, Protocol layering (Book 1 Ch 1)
Application Layer: Application-Layer Paradigms, Client-server applications - World Wide Web and HTTP, FTP, Electronic Mail, DNS. Peer-to-peer paradigm - P2P Networks, Case study: BitTorrent (Book 1 Ch 2). 		6 Hours
Module 2 Transport Layer: Services, Protocols, UDP, TCP (Book 1 Ch 3).
Hands-on: Sockets Introduction, Elementary TCP Sockets, TCP Client/Server Example, I/O Multiplexing: The select and poll Functions (Book 2 Ch 3 to 6), Elementary UDP Sockets (Book 2 Ch 8), Advanced I/O Functions (Book 2 Ch 14).

Network Layer: Introduction, Network-layer protocols, Unicast routing, Multicast routing - Multicasting Basics, Intra domain and inter-domain routing, Next generation IP (IPv6), Quality of Service (Book 1 Ch 4 & Ch 8).
Hands-on: Linux Kernel Implementation of Routing Table and Caches, Routing Cache Implementation Overview, Adding new entry in the Routing Table using ip command (Book 3 Ch 14). 		18 Hours
Module 3 Data-Link Layer: Data link control (DLC), Multiple access protocols (MAC), Link-layer addressing, Ethernet protocol, Connecting devices (Book 1 Ch 5), Wireless LANs, Mobile IP (Book 1 Ch 6).
Hands-on: Datalink Provider Interface, SOCK_PACKET and PF_PACKET (Book 2 Ch 29). 		11 Hours
Module 4 Network Management: SNMP, ASN.1 (Book 1 Ch 9).
Physical Layer: Data and signals, Digital transmission, Analog transmission, Bandwidth utilization, Transmission media (Book 1 Ch 7). 		9 Hours
